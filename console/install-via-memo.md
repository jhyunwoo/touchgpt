# 터치짐 메모에 콘솔 스크립트를 저장해서 쓰는 법 (깨짐 방지)

콘솔 스크립트(`touchgpt.js`)를 터치짐 메모 칸에 **원본 그대로** 저장하면, 메모가 HTML
폼이라 따옴표·`<`·`>`·`&` 를 엔티티로 바꾸거나 길이 제한으로 잘라서 붙여넣을 때
`Invalid or unexpected token` 에러가 납니다.

해결: 스크립트를 **base64로 저장**합니다. base64는 `A–Z a–z 0–9 + / =` 문자만 쓰므로
메모가 건드리지 못합니다. 실행은 짧은 **로더 한 줄**로 합니다.

## 1) 메모에 저장할 것 — base64 블롭

`console/touchgpt.b64.txt` 파일의 **내용 전체(한 줄)** 를 복사해서 터치짐 **메모 칸에
붙여넣고 저장**하세요.

> ⚠️ 워커가 폴링하는 메일박스 회원(`TOUCHGYM_SEQ`, 예: 5971817)의 메모에는 넣지 마세요.
> 그 메모는 질문/답변 채널이라 매번 다시 쓰여집니다. **다른 회원의 메모 칸**에 보관하세요.

## 2) 실행할 때 — 콘솔에 로더 한 줄 (직접 입력/붙여넣기)

```
eval(atob(prompt()))
```

- 이 한 줄은 `< > & " '` 같은 변형 위험 문자가 전혀 없어 어디서 복사해도 안 깨집니다(외워서 쳐도 됨).
- 실행하면 입력창이 뜹니다. **1)에서 저장해 둔 base64를 메모에서 복사해 그 입력창에 붙여넣고 Enter.**
- 스크립트가 로드되고 한글 메시지도 정상 출력됩니다. 이제 사용:

```
ask("질문 내용")
models()
setModel("gemini:gemini-2.5-pro")
```

## 원리
- base64 → 메모가 손상시키는 문자가 없음(엔티티 변환/스마트따옴표 무관).
- 입력창(`prompt`)으로 받으므로 따옴표로 감쌀 필요가 없음 → 따옴표 변형 문제 회피.
- 한글은 빌드 시 `\uXXXX` ASCII 이스케이프로 들어가 있어, 실행 시 다시 한글로 표시됨.

## base64를 다시 만들려면 (스크립트 수정 시)
```sh
npx -y esbuild console/touchgpt.js --minify | base64 -w0 > console/touchgpt.b64.txt
```
